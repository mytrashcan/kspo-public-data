# kspo-public-data

한국체육산업개발(주) 공공데이터 활용 경진대회(2026) 출품을 준비하는 저장소입니다.
백엔드 개발자의 포트폴리오 프로젝트로, 데이터 선정부터 API 연동과 서비스 구현까지의 과정을 기록할 예정입니다.

## 현재 상태: 기획 단계 / 스캐폴드

최종 앱 아이디어와 사용할 데이터셋은 아직 정하지 않았습니다. 현재 코드는 FastAPI 실행 기반,
`GET /`, `GET /health`, 범용 비동기 JSON API 클라이언트와 네트워크 없는 단위 테스트만 제공합니다.
실제 데이터셋 연동과 사용자 대상 서비스 기능은 아직 구현·검증하지 않았습니다.
데이터베이스, 프런트엔드 프레임워크, Docker는 포함하지 않습니다.

## 공모전 안내

- 대회명: 한국체육산업개발(주) 공공데이터 활용 경진대회(2026)
- 주최·주관: 한국체육산업개발(주)
- 접수 기간: 2026-11-02 ~ **2026-12-01 18:00 KST**
- 공모 요건: 기관 개방 공공데이터 57종 중 1종 이상을 활용한 사례(웹·앱 개발, 실감형 콘텐츠 등). 타 기관 데이터 공동활용 가능
- 제출서류: 참가신청서·기획서·개인정보 수집·이용 동의서(공식 첨부서식)
- 접수 방법: 이메일 `data@ksponco.or.kr`

출처: [주최기관 공식 공고 및 첨부서식](https://www.ksponco.or.kr/contestParticipation/62?mid=a10201030000).
제출 전 최신 공고와 첨부서식을 다시 확인합니다. 준비 항목은 [제출 체크리스트](docs/contest.md)에 정리합니다.

## 실행 방법

Python 3.12를 사용합니다. 저장소 루트에서 실행하세요.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

`.env`에 `DATA_GO_KR_KEY`를 입력합니다. 공공데이터포털의 **일반 인증키(Decoding)** 를 사용하며,
클라이언트가 쿼리 파라미터를 인코딩합니다. 선택한 데이터셋의 공식 API 문서를 확인한 뒤
`KSPO_BASE_URL`에 서비스 기본 URL을 입력하세요. 데이터셋이 미정이므로 기본 URL도 비워 두었습니다.

**API를 호출하려면 `.env`의 `DATA_GO_KR_KEY`가 필요합니다. 키와 `.env`는 절대 커밋하지 마세요.**
운영체제 환경변수로도 설정할 수 있으며, 환경변수가 `.env`보다 우선합니다.
키나 기본 URL이 없어도 앱 실행과 상태 확인, 테스트는 가능합니다. 누락된 설정은 실제 API 요청 시
`KspoApiError`로 알립니다.

```sh
python -m uvicorn app.main:app --reload
```

실행 후 <http://127.0.0.1:8000/>와 <http://127.0.0.1:8000/health>에서 확인할 수 있습니다.
`/health`는 프로세스 상태와 키 설정 여부만 반환하며, 키 값이나 외부 API 연결 상태를 노출하지 않습니다.

```sh
python -m pytest
```

가상환경 활성화 후 `make install`, `make run`, `make test`도 같은 작업을 수행합니다.
테스트의 응답은 동작 검증을 위한 합성 입력이며 실제 공공데이터 응답을 재현한 자료가 아닙니다.
테스트는 외부 네트워크를 사용하지 않습니다.

## 데이터 출처 및 연동 범위

공모전 안내 기준 데이터 출처는 [공공데이터포털(data.go.kr)](https://www.data.go.kr)의
**한국체육산업개발(주) 개방 데이터 57종**입니다. 이 중 사용할 데이터와 활용 목적을 선정해야 합니다.

`app/kspo_client.py`의 `KspoClient.get(dataset_path, params)`는 호출자가 지정한 데이터셋 경로와
파라미터에 인증키(`serviceKey`)를 더해 GET 요청하고 JSON을 반환합니다. 데이터셋 ID, 엔드포인트,
업무 필드, JSON 응답 형식을 선택한 데이터셋의 공식 문서에서 확인해야 합니다.
JSON 형식 지정이 필요한 API는 해당 파라미터도 호출자가 전달합니다.

현재 클라이언트는 HTTP 200 이외의 응답, 통신 실패, 잘못된 JSON과
루트·`header`·`response`·`response.header`의 `resultCode` 오류를 `KspoApiError`로 처리합니다.
성공 코드는 `0`, `00`, `0000`으로 한정하며, 실제 데이터셋의 성공 코드와 응답 구조는 선정 후 대조해야 합니다.
파일 데이터 다운로드와 XML 응답 처리는 현재 범위에 포함하지 않습니다.
