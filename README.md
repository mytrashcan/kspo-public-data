# 함께 운동 시간표

**같이 가서, 각자 운동할 수 있을까요?**

일산스포츠센터에서 두 사람이 함께 갈 수 있는 서로 다른 강좌와 **월 회비**를 계산합니다.
공통 요일의 **동시 조합 → 연속 조합** 순서로 보여주고, 성립하지 않으면
누가 어떤 요일을 추가하거나 예산·시간·종목 조건을 얼마나 바꿔야 하는지 실제 강좌와 함께 제시합니다.
한국체육산업개발(주) 공공데이터 활용 경진대회 MVP입니다. 로그인·인증키·외부 네트워크 없이 실행할 수 있습니다.

## 공모전 안내

- 대회명: 한국체육산업개발(주) 공공데이터 활용 경진대회(2026)
- 주최·주관: 한국체육산업개발(주)
- 접수 기간: 2026-11-02 ~ **2026-12-01 18:00 KST**
- 공모 요건: 기관 개방 공공데이터 57종 중 1종 이상을 활용한 사례(웹·앱 개발, 실감형 콘텐츠 등). 타 기관 데이터 공동활용 가능
- 제출서류: 참가신청서·기획서·개인정보 수집·이용 동의서(공식 첨부서식)
- 접수 방법: 이메일 `data@ksponco.or.kr`

출처: [주최기관 공식 공고 및 첨부서식](https://www.ksponco.or.kr/contestParticipation/62?mid=a10201030000).
제출 전 최신 공고와 첨부서식을 다시 확인합니다. 준비 항목은 [제출 체크리스트](docs/contest.md)에 정리합니다.

## 설치와 실행

Python 3.12를 사용합니다. 저장소 루트에서 실행하세요.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

<http://127.0.0.1:8000/>에서 **예시 채우기 → 함께 갈 수 있는 조합 찾기**를 누릅니다.
A·B 모두 화·목 18:00–19:00, 월 예산은 각각 100,000원·70,000원입니다.
실제 강좌 `1029879` TRX(월 100,000원)와 `21832` 농구(월 35,000원)가
화·목 18:00–18:50에 겹칩니다. 합계 월 회비는 135,000원입니다.
같은 시간의 기구필라테스(`1021205`)는 월 160,000원이므로 예시의 예산으로는 나오지 않습니다.
강습반 원문은 각각 `성인남여`·`청소년`입니다. 사용자의 수강 자격을 판정한 결과가 아닙니다.

처음 실행하면 2026-10 원본 행 fixture로 `var/courses.sqlite3`를 만듭니다.
DB가 이미 있으면 재수집하지 않고 해당 DB를 사용합니다. 파일을 다시 수집한 뒤에는 서버를 재시작하세요.
`KSPO_DB_PATH` 환경변수로 DB 위치를 바꿀 수 있습니다. 화면은 Jinja2·로컬 CSS로 렌더링하며 JS·CDN·빌드 단계가 없습니다.

| 경로 | 동작 |
|---|---|
| `/` | 두 사람의 요일·시각·선호 종목·제외 종목·최대 월 회비 입력 |
| `/plan` | 조합, 최소 변경 제안, 조건을 보존한 공유 URL |
| `/evidence?a_code=1029879&b_code=21832` | 선택한 강좌의 모든 원본 CSV 필드와 출처 |
| `/meta` | 기준 월, 데이터셋 ID, 파일명·SHA-256, 행 수·강좌 수, 수집 시각 |
| `/health` | 기존 프로세스 상태 및 선택적 API 키 설정 여부 |

`/plan`은 GET 요청입니다. 사람별 접두사는 `a_`, `b_`이며 `days`는 반복 파라미터,
`start`·`end`는 `HH:MM`, `budget`은 원 단위 정수(빈 값은 제한 없음),
`sport`는 원문 종목명, `exclude`는 반복 가능한 제외 종목입니다.
요일을 선택하지 않으면 허용 요일이 없는 상태로 계산합니다.
공유 링크는 같은 데이터 DB에서 같은 조건과 결과를 재현합니다. 데이터 재수집 후에는 결과가 달라질 수 있습니다.

## 전체 CSV 수집

출처는 [한국체육산업개발주식회사_일산스포츠센터 강좌정보](https://www.data.go.kr/data/15114776/fileData.do),
데이터셋 ID `15114776`입니다. CSV를 내려받은 뒤 다음 명령으로 수집합니다.

```sh
.venv/bin/python -m app.ingest /tmp/kspo_ilsan.csv
# 다른 DB 위치를 사용할 경우
.venv/bin/python -m app.ingest /path/to/ilsan.csv --db var/ilsan.sqlite3
KSPO_DB_PATH=var/ilsan.sqlite3 .venv/bin/python -m uvicorn app.main:app
```

로더는 CP949 → UTF-8 BOM → UTF-8 순서로 디코딩을 시도하고 필수 헤더도 확인합니다.
요일·시간·월·금액이 누락되거나 잘못된 행을 제외하고 사유별 개수를 로그로 남깁니다.
여러 오류가 있는 행은 사유마다 집계하므로 사유별 합계가 제외 행 수보다 클 수 있습니다.
기준 월은 `시작월`의 최댓값이며 **그 월의 유효 강좌만** SQLite에 저장합니다.
최신 월에 유효한 강좌가 없으면 이전 월로 조용히 대체하지 않고 오류를 냅니다.
메타데이터의 `row_count`는 CSV 전체 행 수, `valid_row_count`는 정규화된 전체 행 수,
`course_count`는 저장한 최신 월 강좌 수, `generated_at`은 UTC 수집 시각입니다.
파일 해시는 실제 입력 파일 전체 바이트의 SHA-256입니다.

제공된 전체 파일 실측: 원본 17,146행 → 유효 17,073행(시간 오류 3행, 금액 오류 70행).
최신 `2026-10`은 원본 157행 → 유효 155강좌이며, 종료 시각과 시작 시각이 같은 2행을 제외합니다.
저장소에는 약 27KB의 최신 월 fixture만 포함합니다. 전체 CSV와 `var/` DB는 커밋하지 않습니다.
fixture 출처·추출 방식은 [data/fixtures/README.md](data/fixtures/README.md)에 기록했습니다.

## 조합과 최소 변경 계산 규칙

- 두 사람 각각 강좌의 **모든 기재 요일**과 전체 수업 시간이 허용 범위에 포함되어야 합니다.
  자유 이용일을 별도로 식별할 수 없어, 요일 필드에 포함된 주말도 동일하게 취급합니다.
- 서로 다른 강좌번호, 같은 센터·기준 월, 공통 요일이 필요합니다. 종목이 같아도 강좌번호가 다르면 비교합니다.
- 동시 조합: 겹치는 시간이 0분 이상인 조합입니다. 한 수업이 끝나는 순간 다른 수업이 시작하는 경우도 포함합니다.
  합계 월 회비 오름차순 → 겹치는 시간 내림차순입니다.
- 연속 조합: 겹치지 않고 두 수업 사이가 1~60분인 조합입니다. 합계 월 회비 → 수업 간격 순입니다.
- 현재 조건으로 두 종류 모두 없을 때만 변경을 제안합니다. 각 변경 유형에서 가능한 실제 조합을 전수 비교해
  요일은 추가 요일 수(사람별 합산), 예산은 추가 월 예산 합계, 시간은 앞당김·늦춤 분 합계,
  종목은 제한을 해제할 인원 수가 최소인 제안을 하나씩 고릅니다.
- 한 유형만 바꿔서는 성립하지 않으면 여러 조건을 함께 바꾸는 제안 하나를 고릅니다.
  제안의 정렬 및 복합 변경의 우선순위는 변경 항목 수 → 추가 월 예산 → 추가 요일 수 → 시간 확장 분 → 종목 변경 인원 → 합계 월 회비입니다.
  각 사람의 요일 집합 추가, 예산 변경, 시작 시각 변경, 종료 시각 변경, 종목 제한 해제를 각각 한 항목으로 셉니다.
  서로 다른 비용 단위에 대해 유일한 전역 최적해라고 주장하지 않습니다.
- **모든 제안은 바뀐 조건으로 검색을 다시 실행**하고 제시한 근거 조합이 실제로 나오는지 검증합니다.
  예산 증액은 실제 결제액 증가가 아니라 입력한 예산 상한 대비 필요한 증가입니다. 실제 월 회비는 별도로 표시합니다.
  요일·시간만 바꾸는 경우 추가 예산은 0원입니다. 모든 제한을 해제해도 불가능하면 그 사실을 표시합니다.
- 엔진은 모든 조합을 계산합니다. 화면에는 유형별 상위 20개와 전체 개수를 표시합니다.

## 데이터 한계를 표시하는 이유

주최기관 데이터의 의미를 과장하지 않고, 사용자가 원문으로 판단할 수 있도록 모든 페이지에 기준 월·출처·고지를 표시합니다.

- `정원`은 잔여석이 아니며 수강 신청 가능 여부를 보장하지 않습니다. 등록 상태·실시간 좌석 정보가 없습니다.
- `금액`은 **월 회비로 해석**합니다. 전체 강좌 기간의 총액·할인·추가 비용은 계산하지 않습니다.
- `강습반`은 원문만 표시합니다. 아동 대상·성인 전용 등 자격을 추론하지 않습니다.
- `시작일`에는 기간 문자열이, `종료일`에는 실제 시작일이 들어가는 사례가 있습니다.
  두 필드를 원문 보존하고, 월 판정에는 사용하지 않습니다. `9999-12-31`을 운영 중이라는 표지로 사용하지 않습니다.
- 소개문의 `2013 ~ 2025-08` 대신 **파일에서 계산한 기준 월**을 표시합니다. 현재 달 시간표라는 보장은 없습니다.
- 이용허락 유형은 CSV에 없습니다. [원 제공처 이용허락범위](https://www.data.go.kr/data/15114776/fileData.do)를 확인해야 하며,
  확인하지 못한 유형을 임의로 표기하지 않습니다. 근거 화면에도 같은 안내를 표시합니다.

## 테스트

```sh
.venv/bin/python -m pytest
```

테스트는 외부 네트워크와 `/tmp/kspo_ilsan.csv` 없이 실행됩니다.
실제 최신 월 fixture와 격리된 임시 SQLite를 사용하며, 개별 경계 조건은 합성 입력으로 검증합니다.
인코딩·날짜 열 함정·결측·요일·시간 오류, 동시/연속 조합, 각 변경 유형·복합 변경·완전 실패,
입력/결과/근거/메타/상태 API, 예시 폼 제출, 공유 URL 및 부적절한 화면 문구를 검사합니다.
필수 고지 자체에 금지 단어가 들어 있어 **정확한 고지 한 문장만 예외**로 허용하고,
그 밖의 화면에서 `잔여석`·`신청 가능`·`대기시간` 문자열이 없음을 검사합니다.

가상환경 활성화 후 `make install`, `make run`, `make test`도 사용할 수 있습니다.
기존 `app/kspo_client.py`는 선택적 범용 JSON 클라이언트로 유지하지만 이 MVP의 데이터 경로에서는 사용하지 않습니다.
해당 클라이언트를 별도로 사용할 때만 `.env.example`의 인증키·기본 URL 설정이 필요합니다. 키와 `.env`는 커밋하지 마세요.
